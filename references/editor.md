# 10단계: 셀피쉬 편집기에서 다듬기

편집 화면은 항상 스킬 안 `tools/editor/`로 연다. HyperFrames 스튜디오(`hyperframes preview`)로 열지 않는다. HyperFrames는 렌더 엔진으로만 쓴다. 참가자가 직접 끌고 고치고 「Claude에게 보내기」로 말하는 것이 이 워크숍에서 배우는 흐름이다.

## 열기

```bash
node <스킬>/tools/editor/server.ts --project 편집/<폴더> --port 4317
```
→ 브라우저에서 http://localhost:4317 . 포트가 쓰이고 있으면 4318 등으로 바꾼다. 서버는 백그라운드로 띄우고, 끝나면 끈다.

## 참가자에게 알려 줄 것 (짧게)

| 하고 싶은 것 | 어디서 |
|---|---|
| 훅 바꿔 보기 | 위쪽 「훅 A · B · C」 탭. 글자 · 끝 시각도 여기서 고침 |
| 자막 모양 · 움직임 바꾸기 | 오른쪽 스타일 패널: 먼저 **무엇을**(자막 · 훅 제목 · 말풍선 · 챕터) × **어디에**(전체 · 선택한 것만 · 같은 역할)를 고르고, 「글자 · 상자 · 강조 · 모션 · 위치」 칸에서 값을 하나씩 바꾼다. 따로 바꾼 값에는 • 표시. 되돌리려면 「이 범위에서 바꾼 값 지우기」 |
| 자막마다 다르게 | 자막을 고르고 역할(일반 · 강조 · 질문 · 숫자 · 마무리)을 달면, 같은 역할끼리 한 번에 모션 · 색을 바꿀 수 있다 |
| 색 고르기 | 색 칸의 색 선택기 · #hex 입력 · 💧 스포이트(화면 어디서나, 또는 레퍼런스를 클릭). 레퍼런스 색 · 최근 색 칩 |
| 레퍼런스랑 비교 | 왼쪽 레퍼런스 나란히 보기(같이 재생 · 프레임 넘기기) + 대조표(항목별 맞음 / 더 가깝게 / 일부러 다르게, 「→ 적용」) |
| 다른 느낌 시작점 | 「시작점 불러오기」(프리셋 21개) → 불러온 뒤 값을 고친다 |
| 줌 · 카메라 효과 | 효과 팔레트에서 골라 재생 위치에 넣기, 노란 동그라미로 줌 중심, 길이 · 세기 · 움직임(부드럽게 · 툭 · 튕김) |
| 내 스타일 | 「내 스타일 저장」 · 불러오기 · 파일로 내보내기(`my-style.json`) |
| 자막 고치기 | 화면에서 끌어 위치, 오른쪽에서 글자 · 시각 · 크기 |
| 장면 컷 · 캐릭터 | 넣은 것을 끌어 옮기고 시각 조절 |
| 메모 남기기 | 재생하다 F → 그 시각에 메모 |
| Claude에게 고쳐 달라기 | 「Claude에게 보내기」 → 대화창에 "편집기 확인해 줘" |

## Claude가 피드백 받는 법

1. `편집/<폴더>/editor-inbox/`의 가장 새 파일을 읽는다(대기 메모 · 보낸 말 · 재생 위치).
2. `video/main/edit.json`을 고친다. 편집기가 열려 있으면 새로고침하면 보인다.
3. 반영한 메모는 `status: "done"`.
4. `index.html`은 자동으로 만들어지는 파일이라 직접 고치지 않는다.

사람이 "됐어요"라고 할 때까지 반복한다. 매번 무엇을 바꿨는지 한두 줄로 알린다.

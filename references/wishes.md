# 3단계 ②: 자막 기본 확인 · 본인 바람

**목적:** 편집을 시작하기 전에 본인이 바라는 것을 먼저 듣는다. 레퍼런스나 Claude 추천이 본인 바람을 덮지 않게, 기본 모양(자막 글꼴 · 크기 · 색 · 위치)을 미리 정해 둔다. 여기서 받은 답은 이후 모든 단계에서 가장 앞선다.

## 질문 (한 번에 하나)

**① 꼭 강조됐으면 하는 부분**
> 이 영상에서 꼭 강조됐으면 하는 낱말이나 장면이 있으세요?
> 1. 있어요 (말로 알려 주세요)
> 2. 1단계 「힘준 문장」 중에서 골라 주세요 — 후보 3개를 시각과 함께 보여 준다 (코어: 고객이 겪는 상황에 가까운 것에 ★)
> 3. 알아서 해 주세요

**② 자막 기본 모양** — 편집기에서 첫 자막 하나를 띄워 놓고 묻는다. 말로 설명하지 않고 바꿔 가며 보여 준다.
- 글꼴: 6종 카드(프리텐다드 · 검은고딕 · 주아 · 도현 · 고운돋움 · 나눔손글씨 펜)를 같은 문구로 보여 주고 고르게
- 크기: 작게 / 보통 / 크게 (보통 64~72px, 크게 84px 이상)
- 색: 흰 글자 + 검은 테두리 / 흰 상자 + 검은 글자 / 검은 상자 + 흰 글자 / 내 채널 색(있으면) — 스포이트로 영상 속 색을 찍어도 된다
- 위치: 아래(가슴께) / 가운데 / 위 — 얼굴 · 워터마크를 가리지 않는 높이로 제안
- 한 번에 몇 줄: 한 줄씩 / 뜻 단위 1~2줄(추천)

**③ 빼고 싶은 것**
> 영상에 들어가면 싫은 것 있으세요? (예: 귀여운 이모지, 큰 효과음, 노랑 강조, 특정 낱말)

「잘 모르겠어요」면 추천안을 하나 보여 주고 「이 정도면 괜찮아요?」로 확인만 받는다.

```
- 빼 주세요: …
- 그 밖에 한 말: 「…」 (그대로 옮김)
```

이후 단계에서 결정을 말할 때 바람과 관련 있으면 「(본인 바람)」을 붙이고, 레퍼런스 · 추천이 바람과 다르면 바람을 따르고 그렇게 했다고 말한다.

## 자막 모양은 「글자 배경 · 스타일 고르기」 카드 10개로

②의 글꼴 · 색 · 배경은 편집기 스타일 패널의 카드 10개로 한 번에 보여 주고 고르게 한다(같은 자막 문구로 보임): 블랙 블록(기본) · 화이트 블록 · 형광 블록 · 블랙 + 노랑 키워드 · 깔끔 흰 글자 · 예능 굵은 외곽선 · 종이 메모 · 동글 말풍선 · 다큐 담백 · 신문 헤드라인. 고른 뒤 크기 · 위치만 따로 묻는다. 모든 스타일은 번짐 없는 글자, 배경은 줄마다 글자 폭에 딱 맞게 나온다. 모션은 여기서 고르지 않는다(6단계 모션 보드).

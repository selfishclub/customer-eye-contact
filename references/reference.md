# 2단계: 레퍼런스 먼저 고르기

**목적:** 「어떻게 보이게 할지」 기준을 하나 정한다. 본인 레퍼런스가 있으면 그걸로, **없어도 셀피쉬 대표 레퍼런스 3개와 기본 편집 스타일 카드에서 골라 바로 갈 수 있게** 한다. 인터넷에서 「요즘 잘된 영상」을 대신 찾아 주지는 않는다.

**레퍼런스를 편집기 프리셋에 맞추지 않는다.** "이건 흰 상자 프리셋이랑 비슷하네요"처럼 가까운 프리셋으로 바꾸면 같은 프리셋을 고른 사람끼리 결과가 똑같아진다. 레퍼런스에서 **실제 값**(색 코드 · 크기 · 위치 · 상자 · 강조 방식 · 모션 타이밍)을 뽑아 그 값으로 만든다.

## 질문 두 개 (한 번에 하나)

**질문 1 · 내용 레퍼런스**
> 이 영상처럼 **시작하고 흘러가게** 만들고 싶은 영상이 있으세요? (첫 3초 · 말 순서 · 끝맺음을 볼게요)
> 1. 내 저장소 레퍼런스 카드에서 고르기 (`레퍼런스/레퍼런스카드_영상*.md`가 있을 때만 1번에 둔다)
> 2. 링크 줄게요 (릴스 · 쇼츠 · 스레드 · 유튜브)
> 3. 화면 녹화 · 캡처 파일 줄게요
> 4. 없어요 → 코어로 갈게요

**질문 2 · 스타일 레퍼런스**
> **자막 모양 · 움직임 · 줌 · 색**으로 참고하고 싶은 영상이 있으세요? 내용과 상관없이 "이렇게 보였으면" 하는 거면 돼요. 여러 개여도 돼요(자막은 A, 줌은 B처럼).
> 1. 질문 1과 같은 영상
> 2. 링크 · 계정 이름 줄게요
> 3. 화면 녹화 · 캡처 줄게요
> 4. 없어요 → 코어로 갈게요

## 레퍼런스가 없을 때 — 셀피쉬 대표 3개 + 기본 편집 스타일

둘 다 "없어요"(또는 질문 2에서 「없어요」)면 아래를 보여 주고 고르게 한다 — **멈춤**. 프레임 2장씩 붙인 비교판과 6초 미리보기(`assets/refs/R*/preview6s.mp4`)를 보여 준다. 값은 `assets/refs/library.json`.

| | 이름 | 화면 | 어울리는 영상 |
|---|---|---|---|
| R1 | 전체 화면 + 위 큰 제목 | 얼굴이 꽉 차고 위에 두 줄 큰 제목(노랑 강조), 중간중간 화면 캡처 카드, 아래 자막 | 아바타가 정면으로 말하는 영상, 방법 · 순서 설명 |
| R2 | 반반 컷 · 그림판 | 위 절반 검정 그림판(막대 · 숫자 · 아이콘 · 노랑 띠), 아래 절반 얼굴 + 자막 | 숫자 · 비교 · 개념 설명 |
| R3 | 반반 컷 · 화면 보여 주기 | 위 절반 앱 · 문서 화면(스크롤 · 확대), 아래 절반 얼굴 | 도구 · 자료 · 메시지 캡처를 보여 줄 때 |

그다음 **기본 편집 스타일 카드**(편집기 레이아웃): 전체 화면 + 아래 자막 · 위 제목 띠 · 반반 컷 · 글자 전면 카드. R1~R3을 고르면 그 레이아웃이 함께 정해지고, 레이아웃만 고르고 싶으면 레이아웃 카드만 고른다(그때 값은 3단계 바람 + 코어로).

고르면 `assets/refs/<R>/`의 프레임 · 미리보기를 편집 폴더 `refs/`에 복사하고, `library.json`의 그 항목으로 `refs/ref-style.json`을 만든다. 3단계 바람(글꼴 · 크기 · 색 · 위치)과 다른 값은 **바람으로 덮어쓰고** 그렇게 했다고 말한다.

## 받기

`refs/`에 넣는다. 링크는 `yt-dlp`로 받는다. 로그인이 필요하면 본인이 브라우저에서 로그인하거나 화면 녹화를 넣게 한다. 비밀번호는 받지 않는다. 숫자(조회 · 좋아요)는 보이는 것만, 못 읽으면 "미확인".

## 값 뽑기 (스타일 레퍼런스)

1. **프레임:** 앞 6초는 0.25초 간격, 그 뒤 0.5초. 자막이 바뀌는 순간 앞뒤 3장씩 더(모션을 보려고). `refs/<id>/frames/`.
2. **대표 프레임 3장**을 고른다: 일반 자막 · 강조 자막 · 훅(첫 화면).
3. **값을 잰다** (1080×1920 기준으로 환산):

| 항목 | 재는 법 |
|---|---|
| 글자 크기 | 글자 높이 ÷ 화면 높이 → px (예: 4.2% → 80px) |
| 한 줄 최대 폭 · 줄 수 · 한 번에 낱말 몇 개 | 프레임에서 |
| 위치 | 자막 가운데 높이 ÷ 화면 높이 (예: 68%) |
| 글자색 · 상자색 · 외곽선색 · 강조색 | **프레임 픽셀에서 색을 뽑는다**(ffmpeg로 그 자리를 잘라 평균색, 또는 편집기 스포이트). "노랑"이라 적지 않고 `#F5D90A`처럼 |
| 상자 | 있음/없음 · 투명도 · 모서리 둥글기 · 안쪽 여백 |
| 외곽선 · 그림자 | 있음/없음 · 두께 · 퍼짐 |
| 글꼴 느낌 | 굵은 고딕 / 둥근 / 손글씨 / 좁은 디스플레이 → 스킬 안 6종 중 가장 가까운 것 + 굵기 |
| 강조 방식 | 색만 / 형광펜 밑줄 / 강조 상자 / 크게 / 외곽선 색 / 낱말 하나씩 |
| 모션 | 들어오는 방식과 걸린 시간(프레임 수 ÷ fps). 예: "아래에서 올라오며 0.2초", "글자 하나씩 0.04초 간격". 일반 · 강조 · 질문 자막이 서로 다르면 따로 적는다 |
| 자막 바뀌는 리듬 | 한 덩어리 평균 몇 초 |
| 줌 · 컷 | 몇 초마다, 어떤 줌(툭 / 천천히), 세기(얼마나 커지나) |

4. 값을 `refs/ref-style.json`에 쓴다(형식은 편집기 README). 편집기가 이 파일을 읽어 대조표와 「이 값으로 적용」을 보여 준다.

## 내용 레퍼런스 보는 것

첫 3초에 무엇이 보이고 무슨 말을 하나 · 말 순서(문제 → 이유 → 방법 → 끝) · 얼굴 말고 무엇이 끼어드나 · 끝맺음(질문 · 행동 권유 · 담담).

## REFERENCE.md

```
# 레퍼런스
## 내용 R1: <링크/파일> (본인이 줌, <날짜>)
- 첫 3초 / 순서 / 끝: …
- 가져올 것(구조만): …
- 가져오지 않을 것: 문장 · 사례 · 얼굴 · 음악 · 내 규칙에 걸리는 것

## 스타일 S1: <링크/파일>
- 대표 프레임: refs/S1/frames/일반.png · 강조.png · 훅.png
- 뽑은 값: 글꼴 느낌 … · 크기 80px · 위치 68% · 글자 #FFFFFF · 상자 #111111 85% 모서리 12 · 강조 형광펜 #F5D90A · 모션 일반 아래에서 0.2초 / 강조 쾅 · 리듬 1.6초 · 줌 4초마다 툭 1.12배
- 가져오지 않을 것: 로고 · 캐릭터 · 글꼴 파일 그대로 · 워터마크
```

**뽑은 값은 7단계 「레퍼런스 반영 · 대조」에서 묶음마다 본인 확인을 받는다.** 이 단계에서 바로 확정하지 않는다.

# 단계마다 쓰는 도구 — 무엇을, 왜

참가자가 "이건 뭐예요?"라고 물으면 이 표로 답한다. **각 단계를 시작할 때 그 단계에서 쓰는 도구를 한 줄로 먼저 알린다.** (예: "이번엔 ffmpeg로 쉬는 곳을 잘라요. 영상을 자르고 붙이는 프로그램이에요.")

## 도구 한눈에

| 도구 | 한 줄 설명 | 왜 쓰나 | 비유 |
|---|---|---|---|
| **Claude Code** | 말로 시키면 파일을 읽고 쓰고 프로그램을 돌리는 AI | 아래 도구를 대신 눌러 준다. 사람은 고르고 확인만 한다 | 편집실 실장 |
| **Git · GitHub** | 내 저장소를 받고(Pull) 올리는(Push) 도구 | 내 코어 · 영상이 저장소에 있고, 완성본과 편집 스타일을 다시 저장소에 남긴다 | 공용 서랍 |
| **ffmpeg** (에프엠펙) | 영상 · 소리를 자르고, 붙이고, 줄이고, 사진을 뽑는 프로그램 | 쉼 자르기, 장면 붙이기, 프레임 사진 뽑기, 용량 줄이기 | 가위와 풀 |
| **ffprobe** | ffmpeg에 딸린 "영상 정보 보기" | 길이 · 크기(1080×1920) · 소리 크기를 숫자로 확인 | 자 |
| **Python** (파이썬) | 작은 프로그램(스크립트)을 돌리는 언어 | 받아쓰기 · 쉼 줄이기 스크립트가 파이썬으로 돼 있다 | 엔진 |
| **Whisper** (위스퍼: mlx-whisper · faster-whisper) | 말소리를 글자로 바꾸는 받아쓰기 AI. 내 컴퓨터 안에서 돈다 | 자막 원문과 "몇 초에 무슨 말"을 얻는다. Claude는 소리를 못 들으니 이걸로 읽는다 | 속기사 |
| **Node.js** (노드) | 자바스크립트 프로그램을 내 컴퓨터에서 돌리는 실행기 | 셀피쉬 편집기 서버가 Node로 돈다. 렌더 도구도 Node로 받는다 | 편집기를 켜는 전원 |
| **셀피쉬 편집기** | 이 스킬에 든 브라우저 편집 화면 (http://localhost:4317) | 훅 A · B · C 바꿔 보기, 자막 룩 · 모션, 줌 효과, 끌어서 고치기, 「Claude에게 보내기」 | 편집 책상 |
| **localhost** (로컬호스트) | "내 컴퓨터 안의 주소" | 편집기는 인터넷에 올라가지 않고 내 컴퓨터에서만 열린다 | 내 방 |
| **HyperFrames** (하이퍼프레임즈) | 웹 화면(HTML)을 영상 MP4로 찍어 내는 렌더 엔진 | 편집기에서 본 화면 그대로 MP4로 뽑는다. 편집 화면으로는 쓰지 않고 마지막 "뽑기"에만 쓴다 | 인쇄기 |
| **npx** | Node 프로그램을 설치 없이 그때그때 받아 돌리는 명령 | HyperFrames를 정해 둔 버전(0.9.40)으로 불러 누구 컴퓨터에서나 같게 나온다 | 대여 |
| **GSAP** | 화면 속 글자 · 그림을 움직이는 애니메이션 도구 | 자막 모션 · 줌 · 스티커 움직임. 편집기 미리보기와 렌더가 같은 움직임 코드를 써서 본 것과 결과가 같다 | 안무 |
| **edit.json** | 편집 내용을 적어 둔 파일 (자막 · 훅 · 효과 · 스티커 · 시각) | 편집기에서 고친 것과 Claude가 고친 것이 이 파일 하나에 모인다. 영상 원본은 안 바뀐다 | 편집 설계도 |
| **yt-dlp** (선택) | 링크로 영상을 내려받는 프로그램 | 레퍼런스 링크를 받아 프레임으로 본다. 「찾아 주세요」면 비슷한 주제 쇼츠의 조회수 · 구독자를 모아 줄 세운다(`find_refs.py`). 없으면 화면 녹화를 넣으면 된다 | 복사기 |
| **이미지 도구** (선택: HeyGen 이미지 · ChatGPT · Gemini) | 그림을 만들어 주는 AI | 설명 캐릭터를 한 번 만든다. 돈이 들 수 있어 먼저 묻는다 | 일러스트레이터 |
| **OFL 폰트** | 누구나 나눠 쓸 수 있는 무료 글꼴 (Pretendard · 검은고딕 · 주아 · 도현 · 고운돋움 · 나눔펜) | 자막 글꼴. 스킬에 들어 있어 따로 받지 않는다 | 글씨체 |

## 단계별

| # | 단계 | 쓰는 것 | 왜 |
|---|---|---|---|
| 0 | 준비 · 영상 고르기 | Git(Pull) · ffprobe · 도구 점검 | 최신 저장소에서 시작하고, 영상 길이 · 크기를 숫자로 보여 주려고 |
| 1 | 영상 읽기 | Whisper(받아쓰기) · ffmpeg(프레임 시트 · 쉼 찾기) | Claude는 소리를 못 들으니 글자와 사진으로 영상을 읽는다 |
| 2 | 코어 찾기 · 반영 계획 | Git(브랜치 보기) · Claude Code(파일 읽기) | 코어가 사람마다 다른 곳 · 다른 판에 있어서 찾아서 확인받고, 코어 칸마다 바꿀 것을 정한다 |
| 3 | 레퍼런스 · 값 뽑기 | yt-dlp(선택) · ffmpeg(프레임 · 픽셀 색 뽑기) | 본인이 준 영상에서 색 코드 · 크기 · 모션 시간을 숫자로 뽑아 프리셋이 아니라 그 값으로 만든다 |
| 4 | 훅 3개 | Claude Code · edit.json | 세 가지 훅을 설계도에 넣어 편집기에서 탭으로 바꿔 본다 |
| 5 | 컷 편집 | ffmpeg · 쉼 줄이기 스크립트(Python) | 자르고 붙이는 건 렌더 전에 끝내야 편집기가 가볍다 |
| 6 | 스타일 만들기 | 셀피쉬 편집기(Node) · OFL 폰트 · GSAP | 값으로 스타일을 만들고 자막 역할마다 다른 모션을 준다 |
| 7 | 레퍼런스 대조 확인 | 편집기(레퍼런스 나란히 보기 · 스포이트) · ffmpeg(비교판) | 레퍼런스와 내 장면을 나란히 놓고 묶음마다 확인 — 다 똑같아지지도, 하나도 안 닮지도 않게 |
| 8 | 시각 요소 | 편집기 · 이미지 도구(선택) · ffmpeg(장면 컷 복사) | 장면 컷 · 캐릭터 · 이모지 · 줌 · 끝 처리로 얼굴만 이어지는 지루함을 끊는다 |
| 9 | 편집기에서 다듬기 | 셀피쉬 편집기 · localhost · edit.json | 사람이 하나씩 직접 고르고, 말로 Claude에게 넘긴다 |
| 10 | 렌더 · 검수 · 코어 반영 확인 | HyperFrames(npx) · ffprobe · ffmpeg(검수 사진) | 본 그대로 MP4로 뽑고, 가림 · 오타 · 금지어 · 코어 반영을 확인한다 |
| 11 | 편집 스타일 저장 | 편집기(내 스타일 내보내기) · Git(커밋 · 푸시는 본인 확인 뒤) | 다음 영상부터 같은 결로 바로 나오게 저장소에 남긴다 |

## 자주 나오는 질문

- **"HyperFrames로 편집하는 거예요?"** 아니요. 편집은 셀피쉬 편집기에서 하고, HyperFrames는 마지막에 MP4로 뽑는 데만 써요.
- **"Node가 뭐예요? 꼭 있어야 해요?"** 편집기를 켜는 실행기예요. 없으면 편집기가 안 열려서 0단계에서 설치를 도와드려요.
- **"내 영상이 인터넷에 올라가요?"** 편집기는 내 컴퓨터(localhost)에서만 열려요. 저장소에 올리는 건 마지막에 본인이 정해요.
- **"원본이 바뀌어요?"** 아니요. 편집 내용은 edit.json에만 적히고, 원본은 그대로예요.
- **"렌더가 오래 걸려요."** 처음엔 HyperFrames를 받느라 더 걸려요. 30초 영상이면 몇 분 걸릴 수 있어요.

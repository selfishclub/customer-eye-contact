# 11단계 뒤: 내 편집 스타일 저장

한 번 정한 결을 저장소에 남겨, 다음 영상부터 "지난번처럼 편집해 줘" 한 마디로 같은 결이 나오게 한다.

## 규칙/편집스타일.md

있으면 덮어쓰지 말고 고친 칸에 날짜를 단다.

```
# 내 편집 스타일
> 처음 정한 날: 2026-11-25 · 고친 날: …

## 톤 낱말
다정함 · 담백함 · 살짝 위트 (코어: 말투)

## 자막
- 룩: <편집기 룩 이름> · 모션: <모션 이름> · 강조색: #…
- 위치: 화면 아래 y≈…px (얼굴 안 가림) · 한 줄 최대 …자
- 강조는 한 화면에 하나, 힘준 문장에서만

## 훅
- 자주 고르는 방식: A 영상 속 센 문장 / B 고객 말 / C 레퍼런스 구조
- 등장 · 줌: …

## 시각 요소
- 캐릭터: assets/캐릭터/<이름>.png — 하는 말: 낱말 풀이 · 질문 · 인사 (효과 · 후기 말하지 않음)
- 자주 쓴 효과: 펀치 줌(힘준 말) · 슬로우 푸시(끝) …
- 장면 컷: 아바타 4초 넘으면 끼움

## 레퍼런스에서 가져온 것
- S1 <링크>: 자막 상자 모양, 강조 형광펜 (문장 · 로고는 안 가져옴)

## 넣지 않는 것
- (규칙.md 요약)
```

캐릭터 파일은 `편집/…/assets/`가 아니라 저장소 `assets/캐릭터/`(gitignore 밖)로 옮겨 다음에도 쓴다.

## 편집기록.md (작업 폴더)

```
- 바꾼 것: 훅 A→B, 룩 …, 장면 컷 2곳 …
- 어색했던 곳: …초 입 모양 → 장면 컷으로 덮음
- 다음에 해 볼 것: …
- 완성본: 영상/<이름>_편집.mp4 (<길이>초)
```

마지막에 커밋 · 푸시를 할지 묻는다. 올릴 파일 목록을 먼저 보여 주고, 내 파일만 올린다.

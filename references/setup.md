# 0단계: 준비 · 영상 고르기

목표는 "설치됐다"가 아니라 **받아쓰기 한 번과 편집기 한 번이 실제로 뜨는 상태**다. 첫 질문(영상 고르기)을 점검으로 늦추지 않는다. 영상을 고르는 동안 뒤에서 점검한다.

## 순서

1. **저장소 최신으로 받기.** 지금 폴더가 내 스토리텔링 OS 저장소인지 본다(`코어/`, `영상/`이 있는지). 아니면 "내 저장소 폴더를 열어 주세요"라고 하고 멈춘다. 맞으면 `git pull`. 막히면 덮어쓰지 말고 상태를 먼저 설명한다.
2. **영상 고르기 — 멈춤.** `영상/` 아래 mp4 · mov를 표로 보여 준다: 이름 · 길이 · 크기(가로×세로) · 용량. 추천 순서: 아바타 원본(`아바타_01.mp4`) > 직접 찍은 말하는 영상 > 이미 편집한 영상. 편집본만 있으면 "원본이 있으면 원본으로 다시 하는 게 깔끔해요"를 1번으로.
   - 다른 브랜치에만 영상이 있을 수 있다(`git branch -a`로 확인).
   - 영상이 없으면: 휴대폰 · 드라이브에서 받아 `영상/`에 넣어 달라고 한다. 아바타 영상을 새로 만드는 건 이 스킬 범위가 아니다.
3. **도구 점검.** 결과만 표로 보여 준다.

| 항목 | 확인 | 없을 때 |
|---|---|---|
| ffmpeg · ffprobe | `ffmpeg -version` | 맥 `brew install ffmpeg`, 윈도우 `winget install Gyan.FFmpeg` |
| Python 3.10+ | `python3 --version` | python.org |
| 받아쓰기 | 맥(Apple 칩) `python3 -c "import mlx_whisper"`, 그 밖 `python3 -c "import faster_whisper"` | `pip3 install mlx-whisper` / `pip install faster-whisper`. 첫 실행 때 모델(약 1.5GB)을 받으니 미리 알린다 |
| Node 24+ | `node -v` | nodejs.org LTS |
| 렌더(HyperFrames) | 편집기가 `npx --yes hyperframes@0.9.40`으로 부른다. 처음 부를 때 받기가 시작된다 | 인터넷 연결 확인 |
| 레퍼런스 받기(선택) | `yt-dlp --version` | 없으면 본인이 화면 녹화 · 캡처를 넣는 경로로 간다 |

**렌더가 아무 말 없이 실패하면:** npx 캐시가 반쯤 깔린 경우가 있다. `ls ~/.npm/_npx/*/node_modules/hyperframes` 로 hyperframes가 없는 캐시 폴더를 찾아, 그 폴더 하나만 지워도 되는지 본인에게 묻고 지운 뒤 다시 렌더한다(편집기 README 「렌더가 안 될 때」).

설치는 본인이 동의하면 대신 실행한다. 같은 실패를 반복하지 않는다. 첫 오류와 실행한 명령을 남기고 원인에 맞게 고친다.

4. **작업 폴더 만들기.** `편집/<MMDD>_<짧은이름>/`, `.gitignore`에 큰 파일 폴더 추가(SKILL.md 「작업 폴더」).

## SETUP.md

```
# 준비
- 저장소: <경로> · Pull: 됨 / 막힘(이유)
- 고른 영상: 영상/<파일> · <길이>초 · <가로×세로> · 아바타 / 촬영
- 도구: ffmpeg ✔ · python ✔ · 받아쓰기 ✔(모델 받음) · node ✔
```

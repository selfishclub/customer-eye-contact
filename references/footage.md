# 1단계: 영상 읽기

## 할 일

1. 원본을 `video/main/media/`로 복사하지 말고 아직은 읽기만 한다. 받아쓰기:
   ```bash
   python3 <스킬>/scripts/transcribe.py 영상/<파일> --out 편집/<폴더>/transcripts/
   ```
   원문(`*.raw.*`)은 그대로 두고, 고친 자막은 따로 만든다.
2. 프레임 시트: `bash <스킬>/scripts/contact_sheet.sh 영상/<파일> 1 편집/<폴더>/sheet.png` → 열어 본다.
3. 쉼 찾기: `ffmpeg -i <파일> -af silencedetect=noise=-35dB:d=0.35 -f null -` 에서 0.6초 넘는 쉼.
4. 같은 폴더에 대본(`제작/아바타대본_*.md`, `아바타대본_*.md`)이 있으면 받아쓰기와 대조한다. 아바타가 잘못 읽은 낱말 · 빠진 문장을 찾는다.

## FOOTAGE.md

```
# 영상 읽기 · <파일> (<길이>초)

## 받아쓰기 (문장 · 시각)
| # | 시작 | 끝 | 말 | 메모 |
|---|---|---|---|---|

## 확인할 낱말 — 멈춤
- 「…」(3.2초): 이름 · 숫자 · 업종 낱말이 맞나요?

## 힘준 문장 (훅 · 강조 후보)
| 시각 | 문장 | 왜 (숫자 · 반전 · 질문 · 고객 말) |

## 잘라낼 곳
| 시각 | 무엇 (긴 쉼 · 말실수 · 반복) |

## 어색한 곳 (장면 컷으로 덮을 후보)
| 시각 | 무엇 (입 모양 · 손 · 눈 · 굳은 표정 · 워터마크 자리) |

## 화면 정보
- 얼굴 위치(눈 높이 y≈…px), 자막을 둘 수 있는 자리, 워터마크 위치
```

Claude는 소리를 듣지 못한다. "목소리가 어색하다"는 판단은 하지 않고, 받아쓰기와 음량으로 본 것만 적는다.

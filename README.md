# 고객 눈맞춤 — 내 영상 편집 스킬 (셀피쉬클럽)

> 우리가 만든 영상을 바로 숏폼으로. 컷 편집부터 하이라이트, 모션, 줌, 효과음까지 한 번에 만드는 Claude Code 스킬이에요.
> 레퍼런스가 있어도, 없어도 돼요. 모션처럼 말로 고르기 어려운 건 실제로 움직이는 걸 보고 골라서 한 단계씩 진행해요.

## 이 스킬로 하는 것

- **내 편집기를 만든다.** 내 컴퓨터에 나만의 「셀피쉬 편집기」가 열려요. 이게 메인이에요.
- **찍어 둔 영상을 최종 편집까지.** HeyGen 아바타 영상이든 직접 찍은 영상이든, 완성 MP4까지 같이 가요.
- **하이라이트 3초로 시작.** 영상에서 가장 센 순간 3초를 떼어 맨 앞에 붙여, 첫 3초에 멈추게 해요.
- **레퍼런스는 직접 주거나, 찾아 달라고 하거나.** 내 레퍼런스를 줘도 되고, 「찾아 주세요」라고 하면 비슷한 주제에서 실제로 가장 잘 터진 쇼츠를 조회수 · 채널 크기 대비로 골라 썸네일 판으로 보여 줘요.
- **단계별로 안내받으며.** Claude가 한 번에 질문 하나씩 물으며 0~11단계를 이끌어요.
- **시각화 자료도 만든다.** 이 영상에 필요한 강조 모션 · 카톡 같은 대화 화면 · 숫자 그림판 · 장면 컷을 같이 만들어 화면을 채워요.
- **효과음 · 렌더까지.** 편집기에서 효과음을 들어 보며 다듬고 MP4로 뽑아요. 레퍼런스가 없으면 셀피쉬 기본 편집 틀 4개(전체 화면 · 위 제목 띠 · 반반 컷 · 글자 카드, 틀마다 우리 영상 장면 한 장) 중에서 골라요.

## 시작하는 법

1. 내 저장소(스토리텔링 OS 폴더)를 Claude Code로 열어요.
2. 이 폴더를 `.claude/skills/customer-eye-contact/`에 넣어요. zip이면 Claude에게 이렇게 말해요.
   ```
   이 zip을 내 저장소 .claude/skills/ 에 풀어서 스킬로 설치해 줘.
   ```
3. **「영상 편집해 줘」**라고 말하면 시작해요.

「이 스킬 뭐야?」라고 물으면 Claude가 이 파일로 설명해 줘요.

## 단계 (0~11)

| # | 단계 | 하는 일 | 내가 할 일 |
|---|---|---|---|
| 0 | 준비 | 저장소 최신으로 받기, 영상 목록, 도구 점검 | 편집할 영상 고르기 |
| 1 | 영상 읽기 | 받아쓰기, 사진으로 펼쳐 보기, 센 순간 찾기 | 받아쓰기 오타 확인 |
| 2 | 레퍼런스 고르기 | 「레퍼런스 있으세요?」를 꼭 먼저 물어요. 있으면 내 레퍼런스, 원하면 비슷한 주제에서 제일 잘 터진 숏폼을 찾아 줘요, 없다고 답하면 셀피쉬 기본 편집 틀 4개(우리 영상 장면) | 레퍼런스 있는지 답하기 · 하나 고르기 |
| 3 | 강조 포인트 · 자막 모양 | 내 코어로 이 영상에서 가장 강조할 순간 정하기, 글자 모양 카드 | 「이게 내 코어 맞아요?」 · 강조할 곳 · 글자 모양 |
| 4 | 훅 + 하이라이트 3초 | 첫 3초 제목 3개, 가장 센 순간 3초를 맨 앞에 붙이는 안 | 훅 고르기 · 하이라이트 붙일지 |
| 5 | 1차 편집 | 쉼 · 말실수 자르기, 자막 · 레이아웃 얹기 | 「더 바꿀 곳」 말하기 |
| 6 | 모션 고르기 | 「모션 한눈에 보기」에서 내 자막으로 움직이는 카드 보기 | 역할마다 카드 누르기 |
| 7 | 레퍼런스 반영 · 대조 | 레퍼런스 느낌 입히고 나란히 비교 | 6묶음 하나씩 확인 |
| 8 | 시각화 자료 | 강조 모션, 대화 화면, 그림판, 장면 컷 | 넣을 자리 고르기 |
| 9 | 효과음 | 역할별 효과음 제안 | ▶ 들어 보고 끄고 켜기 |
| 10 | 다듬기 | 편집기에서 직접 고치기, 「Claude에게 보내기」 | 「됐어요」까지 |
| 11 | 렌더 · 저장 | MP4 뽑기, 검수, 내 편집 스타일 저장 | 소리 듣기 · 커밋은 내가 |

## 편집기에서 고를 수 있는 것

- **글자 모양 27개** (블록 · 스티커 · 그라데이션 · 예능 · 감성 · 정보 묶음)
- **자막 모션 31개** (기본 · 통통 귀여움 · 강렬 예능 · 감성 · 정보 · 숫자 느낌으로 걸러 보기), 나갈 때 모션
- **강조 방식 10개**, **줌 · 카메라 효과 24개**, **훅 등장 모션**, **화면 전환**
- **기본 편집 틀 4개**: 전체 화면 · 위 제목 띠 · 반반 컷 · 글자 카드
- **그림판 · 시각 요소**: 숫자 막대 · 게이지, 선 그어 짚기, 대화 화면, 장면 컷, 스티커
- **효과음 12종**: 셀피쉬가 직접 만든 소리, 들어 보기 · 크기 조절
- 글꼴 6종(무료 OFL): 프리텐다드 · 검은고딕 · 주아 · 도현 · 고운돋움 · 나눔손글씨 펜

## 지키는 것

- 내가 한 말은 고치지 않아요(아바타가 잘못 읽은 낱말만 대본대로).
- 효과 · 후기 문장은 자막에는 두되 강조 · 줌 · 효과음에 쓰지 않아요. 의료 업종은 전후 비교 · 환자를 알아볼 사정 · 가격도 넣지 않아요.
- 원본 영상은 건드리지 않아요.
- Claude는 소리를 못 들어요. 효과음 · 목소리는 직접 들어 봐 주세요.
- AI로 만든 영상은 올릴 때 「AI로 만든 콘텐츠」 표시를 켜요. 게시는 본인이 정해요.

## 준비물

- ffmpeg(영상 자르고 붙이는 프로그램)
- Python 3.10+와 받아쓰기(맥: mlx-whisper) — 첫 실행 때 모델 약 1.5GB를 받아요
- Node.js 24+(편집기를 켜는 실행기)
- 인터넷(첫 렌더 때 렌더 엔진 HyperFrames를 받아요)
- 자막 없는 영상 원본

0단계에서 Claude가 하나씩 확인하고, 동의하면 대신 설치해 줘요.
